# 个人字库扩展：清晰分笔与SDT实验

本篇记录旧方案。当前新增真实预训练模型的“离线AI轨迹扩字”，直接根据真实录字生成XY与抬落笔，操作与试样见[个人笔迹OLHWG离线轨迹扩字使用说明](个人笔迹OLHWG离线轨迹扩字使用说明.md)。

2026-11-12新增“个人笔迹学习：真实笔形与部件（离线）”，直接学习真实轨迹并复用个人部件。请优先看[个人笔迹离线学习使用说明](个人笔迹离线学习使用说明.md)；本篇以下内容保留用于旧清晰分笔与SDT对照，不代表新增学习方式。

本功能现在提供“清晰分笔”和“SDT自由生成”两种离线方式。现有自然书写、楷体、黑体、明体以及图片功能保持原来的效果。先关闭旧上位机，再通过“启动上位机.bat”打开新版。

2026-11-12使用“我的手写体”的32个真实录字复查，旧SDT结果中15个新增字有12个只有一笔。“离、线、扩”的模型原始抬笔标记就有问题；不是预览漏画抬笔或机器Z速度导致。改变参考图裁边、粗细没有解决这组样本的失效。先前使用官方笔迹跑通流程，不代表个人字迹已经学好。

| 方式 | 数据与效果 | 局限 |
| --- | --- | --- |
| 清晰分笔：按真实录字校准（默认推荐） | 读取原始录字JSON，校准比例、倾斜与同类笔画曲度；新字保持基础楷体分笔、笔顺和接点 | 仍有基础楷体结构，不能完整推断个人特殊写法或行书合笔 |
| SDT自由生成（实验） | 本地模型根据单字PNG自由预测新字轨迹 | 可能缺笔、错形、连笔；明显的一笔串线会被拦截，其他错误仍需人工核对 |

两种方式都保留已有轨迹、另存新字库。这里没有声称修好了SDT模型，也没有声称训练出了完整个人字体。

## 推荐：用你已有的32字重新生成

1. 打开“文字生成”→“自定义字库 / 100格采样”。选择原始“我的手写体（32字）”，不要选择旧47字扩展库；旧错误字已经存在，继续扩展会原样保留它们。
2. 切到“AI扩展（实验）”，点击“用当前录字生成参考样本并打开AI扩展”。32个原字不必重录。
3. 选择“清晰分笔：按真实录字校准（推荐）”。自动填好的参考目录需含recorded-font.json；灰色模型字段不会使用。
4. 点“检查录字与基础笔顺”。这次32字中27字、115笔参与拟合；其余5字因为合笔数量不同而跳过拟合，原32字仍逐点保留。
5. 新字库名称填“我的笔迹清晰分笔版”，输入“离线扩展需要调用”等短句，每字版本数先选1。
6. 点“生成清晰分笔试样”，完成后“导入本次试样到录字画板核对”。导入为新库，不覆盖原库。
7. 查看“离、线、扩”并回放，新增字应分别有10、8、6笔。每笔后空移到下一笔起点，不应画出多余连接。
8. 返回文字生成选择新库，先关闭“个人字库缺字用基础楷体补缺”和“自然书写”，用同一字号比较新增字与原录字。
9. 沿用已确认的Z基准、XY回零/G54原点及速度，只写短句小样；软件验证不能替代纸面验收。

也可以直接导入exports/个人笔迹_清晰分笔修复试样.json，它含原32字和同一批15个新增字，供核对使用。

清晰分笔以内置9574字楷体结构为底，至少需要15种真实录字，且至少8字、15笔能可靠配对。不猜分笔，不要求将已有合笔字重录。它只迁移有依据的几何特征，不能凭32字推断全部个人部件写法；若某个字必须与你的特殊写法一致，最可靠的方法仍是直接录这个字并替换版本。增加样本可以提供更多校准依据，但不保证所有字都会更像。

此方式只需Python和NumPy，不需要模型、CUDA或联网；本机主界面.venv与已准备的AI Python都能运行。每次最多200种字符、每字1～4版，多版只在有样本依据的曲度权重上小幅变化，不是多种真实手写字体。第一次进入默认清晰分笔，之后记忆上次选择。

以下模型环境说明及纸上参考图方法针对SDT实验方式。清晰分笔直接按上面的画板入口操作即可。

## 1. SDT实验方式是离线还是在线

- 首次准备环境需要联网下载官方源码、约274MB中文模型、内容字形数据和CUDA版PyTorch等依赖。准备脚本只从官方资源下载，不上传笔迹。
- 环境准备完成后，参考图读取、模型推理、轨迹转换和字库保存都在本机完成，不使用在线API、不需要API Key，不按生成字数付费。
- 生成后的JSON字库是普通离线笔画字库。以后用它排版、生成G代码或写字，无需再次加载AI模型，也无需联网。
- 这不是每次从零训练一个模型。预训练模型提供汉字结构，参考样本提供书写风格；推理不会修改模型权重。增加自己的样本后可以重新生成试样，但不会自动把所有汉字永久学会。

模型内容数据支持6763种中文字符，和9574字的内置楷体覆盖范围不同。不支持的未录字会明确报错，不会偷偷漏字。已经录好或已在当前字库里的字保留原轨迹。

## 2. 准备个人样本

推荐先录15～30个不同的字，例如：

```text
永天地人大小上下左右中日月山水火木金土田口国心手学文书写生活
```

不必严格照这段录，也不必录满100格。选择不同结构的字，比复制15份同一张图片更有用。

### 方法A：使用已有录字画板

1. 打开“文字生成”→“自定义字库 / 100格采样”。
2. 选择自己的字库，按原来的方式录字。每个字画好后先“添加为新版本”或“替换当前版本”，再保存字库。画板上尚未加入版本的线条不会成为参考样本。
3. 至少准备15个版本，建议来自15～30个不同字；同一字的少量真实重复版本也可保留。
4. 切到“AI扩展（实验）”，点击“用当前录字生成参考样本并打开AI扩展”。
5. 软件在exports/AI参考样本/<字库标识>/导出单字PNG、samples.json和recorded-font.json，然后自动填好参考目录。

这些参考图确实来自你的录字。原始JSON用于保留手录轨迹，PNG用于提取书写风格。

### 方法B：使用纸上笔迹图片

1. 在白纸上正常写15～30个字，使用扫描软件校正透视、去背景，保留黑色笔迹。
2. 将每个字裁成一张近似正方形图片，字形完整，留少量白边；不要把整行或整页作为一张单字图。
3. 保存为PNG/JPG，每张一个文件，全部放在同一目录。文件名不必就是汉字；模型把这些图作为风格参考，不需要你标注每张写的是哪个字。
4. 在AI扩展页点“使用已有单字图片 / 打开AI扩展”，选择该目录。

笔迹图片中的横线、红色字头、阴影和其他文字可能影响生成；当前版本没有自动整页分字或纸张校正。纸上参考图只能提供风格，不能保证还原你原来每个字的真实笔顺。

## 3. 第一次扩字

1. 先选择“SDT自由生成（实验，需核对字形）”。默认环境Python、官方源码、中文模型和Chinese_content.pkl都指向本上位机.runtime/sdt。若本机环境已经准备好，不需要重新下载。
2. 参考目录选择刚导出的个人目录或裁好的单字图目录。路径会记忆，下次不用重复选择。
3. 点“检查环境与模型”。检查通过表示依赖、显卡、权重、样本和目标字内容数据可读取，不代表生成字形已经合格。
4. “新字库名称”填“我的笔迹扩展第一版”等便于区分的名称。
5. 目标字首次只填8～20个**尚未录制**的字，例如“你好世界学习未来”。如果里面有已录字，它会保留，日志会分别报告新增和保留数量。
6. 每字版本数先选1，样式编号先用2026。
7. 点“生成AI字库试样”，观察进度和具体错误。可随时取消；失败或取消不会覆盖现有字库。
8. 成功后点“导入本次试样到录字画板核对”。它会导入为一个新字库，原字库仍保留。
9. 在单字录制页选择新增字，查看字形并回放轨迹。检查缺笔、错误连接、笔顺和字形是否可接受；需要时手动修正、替换版本，再保存。
10. 返回文字生成，选择这个新个人字库，先保持自然书写关闭，写一行小样。继续沿用原先确认过的Z基准、抬落笔位置、速度、回零和G54纸张原点。

模型能输出带分笔和点序的路径，但不保证每个字的形状、笔顺都正确，也不自动产生真人的压力粗细和连笔。它生成的是风格近似的新字，不是精确复原你从未提供过的真实笔迹。新版会拦截基础结构至少3笔却被预测成1笔的明显失效，并将原始点序保存在本次任务的diagnostics.json；不会导入这批结果。该拦截只能识别部分明显问题，不能证明其他输出正确。

“每字生成版本数”保存同一字的多种候选轨迹；样本少或风格相近时，几个版本可能很相似。建议先用1版核对正确性，再考虑2～4版。现有自然书写开关仍可用于导入后的新字库，本次没有改变其变化算法或现有设置。

## 4. 继续分批扩展

当前每次最多请求200种字符，每字1～4版。先验收小批，再增加数量。

1. 在字库管理中选择上一批已经核对的扩展字库。
2. 点“使用已有单字图片 / 打开AI扩展”。窗口会显示基于当前字库继续扩展。
3. 参考目录仍选择**最初真实手录/纸上笔迹**的目录，输入下一批缺字再生成。
4. 已有字和已经修改过的轨迹保留，新结果另外存成包含原有字符与本批新增字符的字库。

不要反复把生成字导成参考图再喂给模型或校准程序，这样容易逐步偏离自己的笔迹。含SDT或清晰分笔结果的字库不会走自动导出当前录字的快捷入口，仍可使用最初真实参考目录继续扩展。

没有生成的字，可以通过“个人字库缺字用基础楷体补缺”继续书写；不勾选则列出缺字并阻止生成。第一次核对AI字时建议关闭补缺，避免混淆实际来自哪套字形。

## 5. 环境、文件和备份

- 独立Python环境：.runtime/sdt/venv，不向上位机主.venv安装PyTorch。
- 固定版本官方推理源码及原MIT许可：.runtime/sdt/SDT。
- 模型：.runtime/sdt/weights/chinese.pth。
- 官方6763字内容数据：.runtime/sdt/data/Chinese_content.pkl。
- 每次请求、结果和计时摘要：.runtime/sdt/jobs/<任务标识>/，含font.json与summary.json。
- AI路径偏好：config/sdt.json，只保存在本机。
- 导入后的可用字库：config/stroke_fonts/；也可通过原来的“导出JSON”单独备份。

模型、AI环境、个人样本和本地配置默认不纳入Git。换电脑时，字体JSON可直接导入使用；要继续AI扩字，还需迁移模型/环境或重新准备，并保留真实参考样本。

需要重建环境时，在本上位机目录的PowerShell执行：

```powershell
.\准备AI扩字环境.ps1
```

脚本面向本机Windows 64位、Python3.11和NVIDIA显卡。会校验固定源码、模型及内容数据，并直接从官方压缩包按字节提取需要的内容字形，不下载6GB训练集。网络中断后可重新运行，已完成分段可复用。首次CUDA依赖下载约2.45GB，安装后推理不再需要网络。

本机真实验收记录在.runtime/sdt/validation/integration/report.json。可查看同目录ai-complete.png、text-preview.png和trajectories.png；它们使用官方参考笔迹，非你的笔迹。tests/sdt_inference_smoke.py会使用已准备的官方参考图、真实权重与独立环境复验，不连接硬件，也不覆盖常用配置和个人字库。模型加载耗时与逐字推理计时分开，不能把软件推理时间当成写字机执行时间。

本次真实录字的清晰分笔验证见.runtime/sdt/validation/recorded-extension/report.json及同目录截图。tests/recorded_extension_smoke.py复验原字保留、独立分笔、禁止网络后的重复生成、画板导入、G代码回读和模拟任务最终Idle。未连接真实串口，常用配置与原字库前后校验一致。

如果PowerShell执行策略阻止脚本，可在同一目录调用下列命令，不修改全局执行策略：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\准备AI扩字环境.ps1
```
