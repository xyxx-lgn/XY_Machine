# XY写字机上位机 · 第一阶段

Python 3.11 64位 + PySide6，适配当前STM32G431 / GRBL 1.1h工程。

本版实现串口通信、状态、点动及手动控制。顶部文件导入、任务发送、图片生成和文字生成仍禁用，属于后续阶段。纸张视图显示工作坐标标记，不显示G代码轨迹。

## 启动

双击本目录中的 **启动上位机.bat**。已准备好独立的`.venv`，不需要全局安装Python包。

如果双击没有看到窗口，在本目录PowerShell中运行，以查看启动错误：

```powershell
.\.venv\Scripts\python.exe -B main.py
```

重新安装依赖可在本目录运行`安装依赖.ps1`。它只向本目录写入依赖与缓存，不修改系统执行策略。

## 先使用模拟设备

1. 串口下拉列表选择“模拟设备（不连接硬件）”，点击连接。
2. 等待状态为Idle，检查机器与工作坐标不同：WPos = MPos - WCO。
3. 勾选“已按既定流程建立Z基准”。模拟器只在内存中更新坐标。
4. 点击抬笔，等待Idle；测试XY点动和读取设置。
5. 查看“设备 / Z配置”中的步进、舵机设置。

模拟器不模拟机械运动时间、加速度、限位或所有GRBL语义，不能替代实机验收。黄色连接横幅始终明确显示模拟状态。

## 连接真实PCB

1. 关闭Candle、XCOM等占用同一个COM口的软件；按既有硬件流程完整供电。
2. 选择真实串口和115200，连接后先检查状态。软件只自动查询，不自动复位、解锁或运动。
3. 连接初期坐标可能显示未知。WCO是GRBL间歇返回的字段，软件会缓存后换算两种坐标，不会强改`$10`。
4. 点击读取设置，确认固件速度上限；电脑的笔参数不自动写入EEPROM。
5. 按你既有的方法建立Z机器坐标基准后，再勾选确认。该勾选不发送指令，不清零坐标，也不是Z回零。
6. 先抬笔并确认笔尖可靠离纸；等待Idle后再执行XY回零。当前`$H`使用固件已经配置好的XY回零，不包含Z。
7. 在纸张原点处使用“设置G54 XY原点”。它只设置X/Y并写入EEPROM，不修改Z。

如果设备启动处于Alarm，可在排除原因后使用解锁，再建立基准、抬笔和回零。新收到`ALARM:n`时普通发送锁定，先排除故障并软复位。解锁不能恢复失步后丢失的物理位置。

状态超过3秒未更新时禁用手动运动。普通命令应答超时不自动重发，避免重复运动。复位、断开及新报警会清除本次Z基准确认。

## 步进Z

默认抬笔2.0、落笔-0.4，抬笔进给240、落笔120。这些是起始配置，需改成你已经验证的实际参数。Z连杆坐标不是笔尖垂直毫米。

手动抬落笔发送：

```text
G21 G90 G94 G53 G1 Z目标位置 F进给
```

它使用机器Z坐标，不受工作原点影响；同时把普通G代码模态设为毫米、绝对坐标和每分钟进给。XY/Z点动使用`$J=G21 G91 ...`，不改变普通运动的坐标模式。

电脑Z边界默认-1.5到5.0，只用于专用按钮检查，不修改固件限位。控制台原样发送的命令不做完整轨迹验证，运动相关命令会单独提示。纸张范围不等于机器的软限位范围。

## 后续切换舵机

1. 硬件及STM32固件首先切换到支持舵机的版本。
2. 在设备配置中选择舵机Z，填写固件实际支持的单行抬笔、落笔命令。
3. 确认已核实固件，保存。软件会清除旧的Z基准确认，禁用Z坐标点动。
4. 舵机模式的命令默认留空，不假定参考工程的H/V或其他私有命令一定兼容。

界面切换不会给STM32重新烧录。收到ok只代表命令被接受，舵机动作同步需要配套固件保证。当前Z顶部限位仅预留能力字段，未实现`$HZ`。

## 目录

```text
main.py                    程序入口与目录约束
app/profile.py             本地设备配置
app/grbl.py                GRBL状态与命令文本处理
app/transport.py           Qt串口及进程内模拟设备
app/controller.py          应答、状态及手动动作
app/ui/main_window.py      主窗口
app/ui/settings_dialog.py  步进/舵机配置
app/ui/preview_widget.py   纸张和工作坐标
tests/                     协议与模拟界面验证
config/machine.json        首次保存或退出后生成，不写设备EEPROM
logs/host.log              轮转日志，最多约8MB
.runtime/                  依赖缓存、临时文件及界面截图
.venv/                     独立Python环境
```

所有写入均留在本目录。STM32固件和参考工程未修改。网络传输尚未实现，后续可在独立传输层增加ESP32连接。

## 验证

在本目录运行，均不会打开真实硬件串口：

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p "test_*.py" -v
.\.venv\Scripts\python.exe -B tests\gui_smoke.py
```

GUI验证截图保存在`.runtime/screenshots/`。协议测试覆盖串口分包、状态与应答交织、超时不重发、报警、复位、WCO换算、Z范围及舵机切换条件。
