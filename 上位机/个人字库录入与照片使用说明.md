# 个人字库录入与照片使用

## 1. 画板录字

在文字生成窗口点击“个人字库 / 手写与照片录入…”，切到“批量录字清单”。100格是默认起步计划；还可以选择300、1000、GB2312一级3755、GB2312全部6763，或把文章粘贴到清单框后应用。清单最多保存20000个不同字符，录字不要求一次完成。

切到“单字录制”后，选择一格并点“去画板录这一格”。画板中的浅色楷体只用于对照字的大小、位置和宽窄；它不会保存为笔迹。鼠标按下到抬起是一笔，支持数位板，写完点击“保存此格并录下一格”。这个按钮会保存字库并自动进入下一格；重新打开同一个字库后点击“录清单下一个未录字”即可续录。

笔顺编号默认隐藏，录字时不会出现盖住笔画的大数字。需要检查时勾选“显示笔顺编号”，只在每笔起点显示小号数字；它们和楷体参考字均不会混入保存轨迹。个人字库的放弃、取消和删除确认按钮使用中文。

基础100格保留重复字，用于同一个字录多个自然版本。自选文章会自动去重；如果需要同字多版本，可以在单字页用“添加为新版本”。每字最多16版。文字生成打开“自然书写”后会按出现位置稳定地选版本；关闭时使用第一个版本。

“导出当前录字清单的A4采样表”会按每100格分页。标题和字符提示在格子上方，格内只保留十字定位线，避免把印刷参考字误当成手写。按100%实际大小打印，黑色笔书写，不要描画格线。大计划会生成一个“分页”目录，里面有每页SVG、录字清单JSON和使用说明。

## 2. 手机照片录字

在“照片录字”页点击“导入照片”。照片可来自手机拍摄或扫描；程序只在本机处理，不调用在线OCR，也不会上传。本机已经准备离线识字组件，重新启动上位机即可使用；换电脑或重建虚拟环境后，可运行上位机目录内的“准备照片识字.ps1”一次，安装时需要下载依赖，日常识字不联网。不安装组件仍可使用原有手工录字。

普通手稿优先按以下步骤使用：

1. 导入照片，直接点击“自动识字并分字”。不必预先填写字符顺序，也不必逐字画框。可以识别整张照片；初次建议只框选清晰的一两行正文，避免页眉和印刷题目混入。
2. 保持“自动去底与二值化（推荐）”。程序先估计纸面亮度，减轻黄纸和阴影，再自动分离笔迹；不对最终墨迹强行闭合粘连。默认阈值210表示自动模式的正常浓淡，调低减少墨迹、调高增加墨迹，改变后要重新提取。
3. 等待候选列表出现。每项含识别标签、模型分数和落笔路径数；模型分数不是正确率，落笔路径数也不等于真实笔画数。点击候选时原图以橙框显示对应位置，右侧对照“原始单字 / 黑白样本 / 实际书写轨迹”。双击候选或点击“定位本字”可放大到该字；滚轮围绕鼠标缩放（适配大小的1～30倍），按住右键或中键拖动，左键仍用于框选。“适配全图”恢复全图视野，缩放和拖动不会改变已选的原图范围。窗口右上角支持最大化和还原。
4. 自动候选默认不勾选。字形完整、标签却错了：在“本字”输入正确字符，点“修改本字”，只改标签，保留实际照片笔迹。裁切不完整或混入邻字：点“重框本字”，放大后重新框选完整单字并点“提取本张候选”；成功后只替换本项，其他候选和原勾选状态保留。也可点“放弃重框并返回”。局部残痕可用下文的“清理本字”。
5. 逐项核对后勾选；若已检查整张，可点“已核对，勾选有效项”，然后取消不合格项。再点“收录勾选字格”。换照片继续收录，最后“另存为个人字库并返回”。错误候选不会自动写进字库。

识字基于RapidOCR和本地PP-OCRv4模型，支持普通横排文字，手写连笔、密集标点、模糊照片仍可能错认、漏字或分错边界。漏掉的字用原来的“普通段落：逐字框选”补录，不把未识别部分自动当作其他字保存。一张自动识字最多2000个候选，大篇幅分段处理。

自动模式保存的是照片上的真实墨迹提取结果，不会用系统字体替换识别出的字符。它不能恢复真实笔顺，也不是从少量字生成未写字的扩字功能。

### 密集手稿：分离邻字与清理本字

自动识字模式默认启用“沿字间空白分离邻字残痕”。程序在相邻字之间寻找随行变化的空白边界，再把边界以外的墨迹遮白，减少矩形裁切带入邻字的情况。原图上的橙框仍是包围范围，实际保留墨迹可以不是矩形。关闭此选项可与原矩形分字方式对照；改变设置后需重新提取。

字与字已经连写接触、上下行重叠或识字位置有误时，自动分离仍可能留残痕或裁错。程序不采用“只保留最大黑块”，否则会误删点、偏旁和独立笔画。请先放大核对，再用“重框本字”或“清理本字…”处理：

1. 选中候选，点“清理本字…”。新窗口可最大化，显示放大的黑白样本。
2. 默认“擦除残痕”，用左键涂掉属于邻字的黑色小段；笔刷宽度按样本像素设置。误删用“撤销”，也可“恢复本次打开时”。
3. 若黑白样本本身已经断线，可切到“补线（黑色）”，少量修补明确的断口。不要为追求连贯而把原本分开的笔画连起来。
4. 点“应用并重新生成轨迹”，回到三栏核对。该项恢复为未勾选，确认后再勾选收录。取消不改候选；应用只改当前候选，不改原照片或已有字库。

### 删除不需要的提取候选

在右侧列表点击有问题的字，使该行高亮，再点击“删除当前字”。删除只移除这一个候选，其他相同字符的版本继续保留，原照片、已收录批次和已保存字库都不改变。列表编号、橙色定位框、当前预览及自动识字内容会同步更新，其余候选的勾选状态保留。

依次删掉不想要的项，确认剩余字形无误后，点击“已核对，勾选有效项”，再点击“收录勾选字格”。删除后需要恢复，可重新提取照片；重新提取会刷新本张候选，因此建议先完成核对再收录。手工方格模式的字符顺序保持原样，重新提取时仍按原照片格位对应。

### 照片轨迹：连贯单线与旧方式

默认“连贯单线（保留闭环，减少抬笔）”仍依据你自己的墨迹提取书写路线，不替换成楷体。它保留完整闭环，连接原本相通的碎段，并在局部笔宽以内允许极短的原线返回，以减少不必要的抬落笔。不会跨越白纸把两笔强行接在一起。原先黑白图中完整的“口”，不会再因为闭环简化漏掉回到起点的最后一段。

“原中线（旧方式对照）”保留供比较。先确定处理方式，再提取候选；修改轨迹选择会清空本轮待选候选，但已收录批次保留。已有字库保存的是旧轨迹，不会自动改写；要使用新方式，需重新从照片提取并另存字库。

第一次比较新旧轨迹时，若出现“保留当前字库，加入照片补录并另存副本”，请取消勾选，仅收录本次测试的几个字并使用新的字库名。否则旧字形仍在第一个版本，文字生成可能继续选到旧版，让新效果难以判断。确认后再按需要补录到已有字库的副本。

照片无法唯一确定交叉处的真实先后顺序和下笔方向；连贯单线是可绘制路线，不等于恢复人的真实笔顺。固定笔尖也不能通过一条路线完整还原原手写的粗细和压力变化。若必须保留本人真实笔顺，请使用画板或数位板录制。实机速度还受字号、抬笔行程、进给和加速度影响，先用同字号、同参数的小样比较。

方格采样表按下面步骤使用：

1. 选择“方格批量录字”，设置照片行列数。使用本软件采样表时选择“本软件采样表（17mm格）”，并在照片中框选整排方格，不能把标题纳入选区。
2. 普通照片可直接拖动框选；手机斜拍时勾选“四角校正”，按左上、右上、右下、左下依次点击四角。
3. 按照片从左到右、从上到下填写字符，重复字保留；也可从录字清单载入采样表本页字符。推荐使用自动去底，按需调整阈值和格内裁边。“手动阈值（保留原方式）”仍可选；红蓝格线可由“去红蓝格线”清除。使用黑色笔，边框和红线不要进入有效字区。
4. 点击“提取本张候选”。右侧列表显示每格是否成功、黑白样本和实际书写轨迹。逐格点击检查；错误格会保留明确原因，不能静默把后面的字向前错位。取消勾选不合格格，再点“收录勾选字格”。
5. 可以导入下一张照片继续收录。收录的字形会累计，重复字符最多16个版本。确认全部候选后点击“另存为个人字库并返回”。

需要完全手工控制时选择“普通段落：逐字框选”，每次输入一个字并框选它。这也是自动识字出现漏字或错分时的补录方法；普通文章不要通过等大方格硬切。

如果要在已有个人字库上补录，先从字库管理器载入它，再点“导入照片并制作个人字库”。勾选“保留当前字库，加入照片补录并另存副本”，完成后会生成新字库，原字库文件不会覆盖。若旧字库包含真实手写和照片中线，整个新包会标记为“无真实笔顺”，文字生成仍可用，但不会把照片中线宣称为真实笔顺。

## 3. 照片录入的边界

照片只能提供已经写在纸上的字形。程序对黑色墨迹做二值化、去小噪点、保持宽高比例缩放和中线提取；它不能从照片恢复真实落笔顺序，也不会根据少量照片可靠推断没有拍到的汉字。导出的单字照片PNG和`samples.json`可以作为本地SDT图片参考，但不会伪装成真实手录的`recorded-font.json`。

首次使用建议先录10～20字，检查预览后在纸上运行小样。确认阈值、裁边和分格无误，再逐步增加到300或1000字。照片质量、笔宽、纸张阴影和格线都会影响中线结果；不合格字应重新拍摄或回到画板手写录入。

### 照片字形与实际手写的差异

照片中的“黑白样本”是二值化后的墨迹，最接近原照片；“连贯单线/笔形单线”只保留墨迹骨架，适合固定笔尖快速书写，不能恢复原来的笔宽、压力、笔锋和真实下笔顺序，所以写在纸上的外观会比照片更细、更规整。静态照片无法知道交叉笔画先后，这不是阈值高低能够补回的信息。

如果希望尽量接近照片的粗细外观，选择“墨迹还原（轮廓＋填线）”，填写纸上实际笔迹宽度并重新提取。它会把外轮廓和内部填线保存为多条路径，速度更慢、抬笔次数更多，也可能超过单字128条路径或单条4000点的字库上限；超限时程序会拒绝收录并提示清理或改用单线。建议先用“广、宁、和”三字小样比较，再决定整套字库采用哪一种。

自动识字的分数只表示识字标签的可信度，不表示单字裁切完整。相连邻字、跨过分界线的连笔会在列表中标注“连字边界需核对”；请放大照片检查橙色框，必要时使用“重框本字”或“清理本字”。程序现在会先记录跨字连通块，再做保守归属，避免因为“绝大部分属于一个字”而静默吞入邻字残笔，但真实连写仍必须人工确认。原始单字、黑白样本和轨迹三栏都应通过检查后再勾选收录。

各功能窗口的右上角同时提供最小化、最大化/还原和关闭按钮；有未保存照片字形时点击右上角“×”与底部“关闭”会使用同一确认流程。
