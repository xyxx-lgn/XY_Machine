# 自然书写与个人字库

本次只扩展文字笔画功能。图片、系统字体轮廓/填充/骨架、行程检查和发送流程继续使用原实现。先关闭旧上位机，再用本目录的“启动上位机.bat”打开新版。

## 一、先测试自然书写

1. 打开“文字生成”，排版选“正文排版”，路径选“笔画书写”。字号先用已经测试过的18pt，XY/Z速度和抬落笔位置沿用原值。
2. 中文字库先选“XY单线楷体”，英文先选“简洁单线”。输入：

   ```text
   你好你好你好，永永永永永。
   天天学习，好好生活。
   Hello Hello 123 123
   ```

3. 不勾“自然书写”，生成一次并点“放大图案”，相同的字形应一致。
4. 勾“启用自然书写”，先设“字形与笔画变化75% / 字距变化40% / 行内起伏20%”，样式编号保持1，再生成。相同字除了宽窄、倾斜变化，字内比例和长笔画曲度也会小幅变化。先点“放大图案”比较，再做一行实机小样。
5. 参数不动再次生成，轨迹应完全一致。点“换一种自然效果”会换编号并让旧结果失效，需要重新生成。
6. 保存或载入时会记住字库、英文样式、自然开关、三个强度与编号。单纯关闭窗口沿用原来的行为，不额外自动保存生成偏好。

自然变化对内置和个人笔画字库都有效。本次由整字仿射变化扩展为“整字共用的平滑形变场”：长线适量插点后弯曲，字内不同位置有不同变化；已相接的笔端同步移动，不逐点抖动、不拆折笔、不增加填线、不重排原数据。有多个版本时，还会按编号选用不同的真实录字版本。它不会自动产生真人的连笔、正确行书笔顺或压力粗细变化。

三个强度可以独立比较：只看字形时设75/0/0，只看字距时设0/75/0，只看行内起伏时设0/0/75。关闭自然书写，或三个强度均为0，会保持原始轨迹。迁移旧偏好时，原强度会同时用作三个强度的初值；建议手动改为75/40/20后保存一次。新轨迹算法与旧版本不同，因此旧版同一编号的自然轨迹不保证保持一致；本版内重复生成仍一致。

形变不会增加抬落笔次数，但为表现弯曲会增加部分XY线段。本机1000字符样本：关闭时排版0.067秒、当页生成1.324秒；75/40/20时排版0.285秒、生成1.732秒。两者均3942笔，命令由35442条增加到46215条。这是软件测试，不代表机械耗时；先用短文本比较实际效果。

## 二、目前可以选什么字体

- 中文默认“XY单线楷体”，9574字，保留上一版通过实机测试的原始数据及笔顺。
- 新增“XY单线黑体”20976字符、“XY单线明体”27632字符，已随软件打包，不需要自行下载或导入。来源为LingDong-/chinese-hershey-font固定版本，原字体分别是Source Han Sans与Hanazono；许可、来源、校验值见assets/strokes/centerline。
- 黑体、明体使用自动提取的中线路径，不能保证标准笔顺，可能存在分叉、重复描线或局部小缺口；界面和生成说明会明确提示。它们是不同字形的选择，并非两套新个人手写体。需要按笔顺、接点效果稳定时优先用现有楷体或自己录字。
- 英文/数字提供四套真实Hershey数据：简洁单线Futural、手写单线Scripts、花体Scriptc、衬线Timesr。花体和衬线的部分字母包含更多描线，通常比简洁单线慢。
- 中文可新增多个个人笔画字库，导入后出现在同一个下拉框；每个字库都可开启自然书写。
- 系统黑体、宋体仍在原有轮廓/填充/骨架模式中选择；与本次两套固定中线资源不是同一入口。TTF的外轮廓不能直接当成标准笔顺。

新字体测试：中文/个人字库下拉框依次选楷体、黑体、明体，输入同一段“你好世界，永田口中。Hello 123”，先关闭自然变化比较字形，再开启75/40/20比较同字差异。三种字体都逐字写完再写下一字。黑体、明体缺字会阻止生成，不会静默换成楷体；个人字库补缺开关仍只影响个人库。

软件生成的对照图在.runtime/writing-styles-smoke/writing-style-comparison.png。自动测试入口为tests/writing_styles_smoke.py；包含参数记忆、旧偏好迁移、导出与模拟设备完成。

## 三、先录制自己的两三个字

1. 点“个人字库 / 手写与照片录入…”。顶部选“新建个人字库”，名称改成“我的手写体”。
2. 在“当前字”输入一个字，例如“永”。用鼠标或数位板按自己的笔顺在米字格中书写；按下到抬起算一笔，折笔应按住连续写。
3. 画错可以“撤销一笔”，也可以“清空画板”。点“回放笔顺”只在屏幕回放，不会控制电机。
4. 写完点“添加为新版本”。这一步将画板内容加入字库草稿。
5. 清空画板，把同一个字重新写一遍，再点“添加为新版本”。建议每字先录2～3版，最多16版。要修改已有版本，先选择该版本，画好后点“替换当前版本”。
6. 点顶部“保存字库”，再返回文字生成。字库应自动选中刚保存的“我的手写体”。录字画板的内容须先添加/替换为版本，再保存字库；画板上尚未加入版本的线条不会直接成为字库条目。
7. 输入几个已录字并生成。关闭自然变化时固定用第1版；开启后可以选用不同版本，预览和发送保持一致。

“字框宽”是归一化字符的排版宽度，中文通常保留1.00；不是电机脉冲数，也不是毫米。正文实际尺寸由字号决定。

保存后的个人字库在`config/stroke_fonts/`。可“导出JSON”备份，在另一台电脑“导入JSON”后继续使用，所有版本和点序都保留。个人字库目录默认不纳入Git，需要备份时显式导出；本次没有自动提交。

字库管理窗口顶部现在有“删除当前字库”。先在下拉框载入要删除的个人字库，确认没有未保存修改后点击删除并确认。删除只移除本机`config/stroke_fonts/`中的整套个人字库；已经导出的JSON备份、内置字库和其他个人字库不会删除。删除完成后窗口会回到“新建个人字库”。

### 缺字怎么处理

- 勾选“自定义字库缺字时用基础楷体补缺”：已录字使用个人笔迹，其余受支持汉字用基础楷体，生成结果会列出补缺字符。英文与标点仍可用。
- 不勾选：个人库没有的汉字会列出并阻止生成，方便检查哪些字还要录制。
- 连内置库也没有的生僻字、emoji等会阻止生成，可以手动补录，不会悄悄漏字。
- 原来选中的字库文件丢失时会提示重新选择或导入，不会静默换字体发送。

## 四、批量录字和照片录字怎么用

100格只是起步计划，不是字库容量。现在可选100格、300字、1000字、GB2312一级3755字、全部GB2312汉字6763字，或者粘贴自己的文章生成去重清单。单套支持最多20000种字、每字16版，并受200万个轨迹点和读取文件大小限制；特别复杂的大库应拆分。

在“批量录字清单”选好计划，点击“应用录字清单”，选择一格并点“去画板录这一格”。画板默认显示淡色楷体参考，不会混入保存轨迹。写完点“保存此格并录下一格”，会同时保存字库和清单；下次打开选择同一字库，再点“录清单下一个未录字”即可继续。基础100格中的重复格用于同字多版本，需按格号先后录制。

“导出当前采样表”以每100格一张A4输出SVG，大计划放入独立分页目录，附每页字符清单。格内留白、楷体提示在格子上方；照片导入选择“本软件采样表”并框选整排方格，末行空白格也包含在选区。

“照片录字”支持本机自动识字和分字，无需先填写全文或逐字框选；自动去底减轻黄纸、阴影造成的黑块。自动候选须核对标签和裁切后勾选，错字可改标签，裁错可重框单字；原方格清单、四角校正和逐字手工模式保留。可累计多张照片后另存字库；补录也可保留原字库并另存副本。详细步骤见[个人字库录入与照片使用说明](个人字库录入与照片使用说明.md)。

照片方式录入照片上已有的字形，生成中线而非真实笔顺；未拍到的字仍需补录、基础楷体补缺或单独的实验扩字。照片样本可以导出PNG和samples.json供SDT图片参考，不会伪装成真实手录的recorded-font.json。原来的真实手录样本导出仍保留。

## 五、个人扩字：清晰分笔与SDT实验

最新入口增加“个人笔迹学习：真实笔形与部件（离线）”，从XY轨迹学习笔形，并把实际写过的部件用于未录字。使用步骤及参考不足提示见[个人笔迹离线学习使用说明](个人笔迹离线学习使用说明.md)。以下清晰分笔说明保留作旧方案对照，自然书写算法保持原效果。

2026-11-12用用户32个真实录字复查：SDT生成的15个新增字中12个只含一笔，错误连接已经出现在模型原始输出中。更换裁边或加粗参考图没有解决；不能将先前流程跑通当成个人字迹已经学好。

有画板录字时，默认选择“清晰分笔：按真实录字校准”。它从真实录字估计比例、倾斜和同类笔画曲度，再用于内置9574字楷体结构，保留基础分笔、笔顺和接点。无需模型或CUDA，离线运行，不改变自然书写算法。它仍有基础楷体的结构，不能凭32个字推断完整个人行书、特殊合笔或从未出现过的部件写法。

已有的32字不用重录。请从原始“我的手写体”打开扩字入口，重新生成新试样；不要从含错误连线的旧扩展库开始，因为已有轨迹会被原样保留。详细点击步骤和两种方式的区别见[个人字库AI离线扩展使用说明](个人字库AI离线扩展使用说明.md)。以下模型环境说明仅针对“SDT自由生成”。

**当前状态：本机已准备官方中文模型、6763字内容数据及独立CUDA环境，已完成真实推理、离线复现、画板导入和模拟发送。可以开始用自己的参考笔迹生成少量未录字；个人风格和纸面效果仍需试写验收。**

网络恢复后已取得并校验官方资源。具体点击步骤、如何从当前录字生成参考图、如何分批扩字及备份，见[个人字库AI离线扩展使用说明](个人字库AI离线扩展使用说明.md)。本次保持原有自然书写和中线字体效果。

官方项目：[dailenson/SDT](https://github.com/dailenson/SDT)。该模型用预训练知识提供汉字结构，用个人样本提供书写风格。少量样本不能保证准确生成每个汉字，也不能保证模型预测的点序都符合规范笔顺。“online handwriting”在这里指带顺序的轨迹数据，并非上传到在线服务器。

适配器直接读取模型输出的`dx, dy, pen-down, pen-up, end`，累计坐标并按抬笔状态分笔。它不从生成PNG重新提骨架。没有结束标记、无效坐标或字形数据缺失时不会生成可导入字库；失败或取消不覆盖现有字体。

需要单独准备：

1. 官方SDT源码目录，含`models/model.py`。
2. 与官方中文默认网络结构匹配的中文预训练权重。
3. 官方中文内容字形数据`Chinese_content.pkl`；与模型训练使用的内容字形保持一致。本版本用该文件检查目标字支持范围，不默认声称可扩展到全部Unicode汉字。
4. 支持CUDA的独立Python环境。本机RTX 4060 Laptop 8GB已实际跑通，不向主界面Python环境安装PyTorch。
5. 至少15张风格一致的单字白底黑字PNG/JPG，建议从少量清晰样本和8～20个目标字开始。

当前这台电脑无需重复安装。换电脑或重建环境时，在本目录运行以下脚本，下载并校验资源、准备独立依赖；不会连接机器：

```powershell
.\准备AI扩字环境.ps1
```

首次准备需要联网下载模型及约2.45GB的CUDA安装包；中断后可以重跑，已完成分段可复用。准备好后推理不需要网络，也不上传参考图。源码、模型、数据均在`.runtime/sdt/`对应目录，界面也允许选择已有文件。

准备好后：

1. 字库管理→“AI扩展（实验）”→打开SDT窗口。
2. 选择AI环境的Python、源码目录、模型、内容字形文件和参考图目录。
3. 先点“检查环境与模型”，读取具体错误。检查通过只表示环境/权重/输入格式通过，还没有证明生成字形正确。
4. 输入8～20个试字，点“生成AI字库试样”。每次最多200种目标字符，可为每字生成1～4版；模型为每版选择15张样本。样本和模型可能导致多个版本仍很相似。
5. 成功后点“导入本次试样到录字画板核对”。核对字形和回放，保留手录版本，再在文字窗口选择新字库。导出的参考目录带有`recorded-font.json`时，已录字符保留原轨迹，不被AI替换。
6. 首先预览少量字，再按正常机器准备流程做小样。生成、导入及回放都不会自动开始写字。

目前不提供一键把系统黑体/宋体变为正确笔顺、自动OCR识别普通整页手稿、自动修正AI错字、后台训练个人大模型或全字库批量验收。

## 六、建议验收顺序

1. 先按第一节比较自然开关，再分别比较75/0/0与75/40/20。
2. 保存同一编号的G代码，再生成一次，确认轨迹一致；换编号后应改变。
3. 自定义库只录姓名中的2～3字，每字2版，测试补缺开关、备份导入和保存后重开。
4. 载入“模拟设备”完成一个很短的文字任务，确认最终Idle与笔尖抬起。
5. 实机沿用已经验证过的Z基准、XY回零/G54原点和速度，只写一行小样；本次无需修改STM32、GRBL或EEPROM。
6. 看实机效果再调自然强度，最后才考虑AI模型。强度较大并不必然更像自己的字，真实多版本录字通常更直接。

自动验证入口：`tests/natural_writing_smoke.py`。验证使用离屏Qt和内置模拟设备，不连接真实串口；测试配置保存在`.runtime/`，不会覆盖常用机器和生成配置。
