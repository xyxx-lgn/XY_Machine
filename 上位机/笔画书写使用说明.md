# 笔画书写：使用与测试

本次只调整文字生成。正文推荐方式改为“笔画书写（按笔顺，推荐）”；撤下上一版新增的“字体实心书写”入口。原有系统字体轮廓、轮廓＋填充、仅填充、骨架中线，以及图片、导入文件、行程检查和发送通道继续保留。

## 1. 现在怎样写字

汉字直接读取离线字库的有序中线，不再把普通字体栅格化、细化或填实。按行从左到右，每个字的全部笔画完成后再进入下一字。每条笔画一次落笔；横折等转折在同一条轨迹内连续完成。不会为了少走空行程而反转、重排或合并原笔画。

例如“口”是3笔，“中”是4笔，“永”是5笔，“田”是5笔。“口”的第二笔包含横折，不能把它拆成横、竖两次落笔。“田”仍要按原笔顺多次抬落笔，这是实际笔画之间的分隔，不是上一版填线造成的重复扫画。

线条不再按字体粗笔画内部来回填充；实际粗细由笔尖、纸面、落笔位置和弹簧压力决定。预览笔迹线宽只显示笔迹粗细并为页边距留白，不会生成更多填线，也不能把粗笔变成细笔。

## 2. 支持哪些字形

- 中文内置“单线楷体笔画”，来自Hanzi Writer Data 2.0.1，共9574字；英文/数字现可选Hershey Futural、Scripts、Scriptc、Timesr。中文个人笔画库可另行录制和导入，详见[自然书写与个人字库使用说明](自然书写与个人字库使用说明.md)。
- 内置常用中文标点与全角ASCII符号。空格、回车、自动换行、字号、字距、行距、段后间距、缩进、对齐与分页继续可用。
- 笔画模式下，系统字体、粗体、填线、轮廓简化、短线过滤和路径优化禁用，避免设置看似生效却改变不了字形，或把笔顺打乱。
- 自然书写是独立可选项，默认关闭；启用后对整字和排版作小幅变化，不改笔顺和连接。同一编号的预览与实际输出保持一致。
- 黑体、宋体等普通系统字体可以在原有轮廓/填充/骨架模式中使用；本版没有把任意TTF自动转换为标准笔顺的功能。
- 缺字时列出字符与Unicode编号，阻止生成；个人字库可显式勾选用基础楷体补缺，生成结果会列出补缺字。生僻字、emoji、部分外文字符可能需要手动补录。字形和笔顺也可能有地区差异。

字库随程序离线提供，正文不上传网络。来源及许可可点击“字库来源与许可…”查看，也保存在`assets/strokes/`。日常运行无需安装或下载字体数据。

## 3. 先检查这一组字

1. 关闭旧窗口，用本目录`启动上位机.bat`重新打开。
2. 进入“文字生成”，选择“正文排版（固定字号，自动换行）”。向下找到“路径方式”，选择“笔画书写（按笔顺，推荐）”；旧实心入口的偏好会自动迁移，其他已保存模式可手动改选。
3. 字号先选18pt，不改已经验证过的XY进给、Z抬落笔位置和进给。14pt的字框约4.94mm，18pt约6.35mm，实际字迹略小于字框。
4. 输入以下三行，然后点“生成本页轨迹”：

   ```text
   十口中永田国
   你好，世界！HOB 123
   独立笔画，连续折笔。
   ```

5. 点“放大图案”。蓝色实际轨迹应为单线笔画；“口、田、国”的接笔位置相接，不能出现内部密集填线；“永”的点、中文标点和字母孔洞应保留。勾选空行程只会显示抬笔移动，不会让这些灰线落笔绘制。
6. 生成和“载入当前页”都不自动开始，也不连接真实机器。可先保存`.ngc`，重新导入确认预览一致。

## 4. 模拟设备怎样测

1. 主窗口端口选择“模拟设备”，连接。
2. 在文字窗口仅输入“口”，生成并载入当前页。
3. 按模拟设备的现有流程勾选Z基准确认，点抬笔；开始任务。
4. 观察按3条落笔路径完成，所有应答完成且设备返回Idle后，任务才显示完成。继续测试“口中”，应为7条落笔路径。
5. 再将上述三行生成、载入并测试。模拟器能验证命令、状态与范围，不能评价墨迹、机械精度或丢步。

## 5. 实机怎样测

1. 断开模拟设备，按你已验证的完整供电、串口连接、Z基准、抬笔、XY回零和G54纸张原点流程准备。
2. 先写上述18pt三行，使用原来已稳定的速度；先比较形状和笔顺，不同时提高进给。
3. 应能看到一个字写完再写下一字；转折笔内不抬笔，笔画之间正常抬笔。字迹不应再因轮廓内部填充而变粗。
4. 如果预览连续、实机仍断墨，先比较同一位置是否重复断开，并检查笔、纸面、弹簧压力和落笔是否充分；不要用加填线掩盖断墨。
5. 小样通过后，再用相同文本测试14pt。最后粘贴一段不手动回车的中英文段落，检查自动换行、标点和分页。下一页需要换纸、确认定位，并手动开始。

旧`.ngc`不会自动变成笔画字，必须重新生成。若仍觉得字粗，优先换细笔或适当减小落笔压力；调小“预览笔迹线宽”只改变显示与边界留白。

## 6. 修改位置与验证范围

- `app/text_writing.py`：离线字库、中文标点、字框排版与笔画预览。接点只补原轮廓确实交叠、连接位于原墨迹内且沿笔端方向的小缺口，保留原始笔画点和顺序。
- `assets/strokes/`：原始数据、预计算笔画、版本来源和原许可。预计算接点避免每次粘贴正文重新求交；重复字形继续缓存。
- `tools/build_stroke_data.py`：开发时重建汉字数据，校验固定源包SHA256；日常使用无需运行。
- `app/text_layout.py`：保留毫米排版数据和按字输出；有序笔画绕开轮廓、细化、过滤与优化，复用已有G53 Z和G54 XY输出。
- `app/ui/generation_dialog.py`：模式、控制项、旧偏好迁移、缺字提示和本页生成；未改固件参数。
- `tests/test_text_writing.py`与`tests/stroke_writing_smoke.py`：笔顺、接点、缺字、字框范围、换行分页、配置、取消、导出及模拟发送。

本地测试只用离屏界面和进程内模拟设备；实机效果以你的纸面小样为准。

方案参考：[GRBL-Plotter单线字与系统字体的区分](https://grbl-plotter.de/index.php?id=form-text&lang=en)、[Hanzi Writer笔画数据](https://github.com/chanind/hanzi-writer-data)、[Hershey Text绘图字体](https://github.com/techninja/hersheytextjs)。
