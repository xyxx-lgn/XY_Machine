# 第四阶段：文字生成与使用体验

第四阶段在现有串口、G代码预览、行程检查和图片生成基础上，补齐了文字排版与日常排障功能。文字仍然走同一个图片化路径生成器，因此轮廓、填充、孔洞保护、Z/F输出和发送前行程检查与图片任务一致。

2026-11-11更新：文字窗口默认采用固定字号的正文排版，增加自动换行、页边距和分页。新流程见[正文排版第一步使用说明](正文排版第一步使用说明.md)。下文按总宽/总高生成的操作请先选择“文字图案（整体缩放）”；正文模式改为按页生成，字形不再整体栅格缩放。

## 1. 文字生成

1. 启动上位机，点击顶部“文字生成”。
2. 输入英文、数字、中文或多行文字；文本框保留换行和空格。
3. 在字体下拉框选择已经安装的字体，勾选“粗体”可以改变字形笔画宽度。
4. 设置“多行行距”：`1.00×`使用系统默认行距，数值越大行间距离越大；建议先用`1.00～1.30×`。
5. 设置“多行对齐”：左对齐适合普通段落，居中适合标题，右对齐适合右侧对齐的标签。单行文字三种方式的结果基本相同。
6. 选择路径方式：轮廓得到空心字，轮廓＋填充得到先描边再填充，仅填充适合减少重复描边，中线适合细线稿。
7. 设置总宽/总高和G54左上角位置，先点击“生成预览”，检查右侧蓝色轨迹、孔洞、Z范围和命令数量。
8. 点击“载入主窗口”只会载入任务，不会自动运动；点击“保存 .ngc…”只保存文件，也不会发送。

文字生成使用当前设备配置中的纸张与Z边界。生成结果仍需在主窗口开始时读取`$130/$131`并进行G54机器坐标检查；超限会阻止整份任务发送。

## 2. 建议的文字验收顺序

先用模拟设备完成以下四组：

1. 单行`HOB 123`，字体使用常规字体，轮廓模式，确认方向和尺寸。
2. 同一内容改为仅填充，填线间距使用已验证的`0.18 mm`，确认O/B孔洞保持空白。
3. 输入两行`XY Machine`和`写字机测试`，分别尝试左对齐、居中对齐和`1.25×`行距。
4. 选择粗体中文，生成后观察路径数量；路径过多时增大填线间距、简化误差或缩小文字。

模拟设备只验证文件解析、发送、暂停/继续、任务完成和界面状态，不模拟真实电机负载。真实PCB仍按既定流程完整供电、建立Z基准、抬笔、XY回零、设置G54，再先运行小字样。

## 3. Z和XY速度

文字窗口中的XY绘制进给、XY抬笔移动进给、抬笔进给F、落笔进给F都会写入本次G代码。它们不是步进脉冲数；实际运动仍受固件`$110/$111/$112`和`$120/$121/$122`限制。

勾选“载入/保存时记住字体、尺寸和生成参数”后，点击“载入主窗口”或“保存 .ngc…”会保存当前文字设置。下次打开时会恢复文本、字体、粗体、行距、对齐和速度；Z高度仍取设备配置，避免旧任务覆盖新的机械基准。

## 4. 日志导出

主窗口“通信与操作日志”区域新增“导出日志…”按钮。它导出当前界面显示的日志到`.log`或`.txt`文件，适合保存报警、发送进度和设备应答，默认目录为上位机`logs/`，也可以选择其他有写权限的目录。

日志导出不会发送串口命令，不会修改EEPROM。大文件任务默认只显示任务摘要；需要定位某一条指令时勾选“显示逐行收发”，再导出日志。

## 5. 常见错误

- “任务检查未通过”：先看弹窗中的原文件行号、轴、机器坐标和允许范围，缩小或移动文字后重新生成。
- “设备报警ALARM:1”：检查限位开关和机械位置，软复位后重新确认坐标和Z基准。
- “设备报警ALARM:2”：是软限位，检查G54、纸张原点、任务尺寸和`$130/$131`，不要直接关闭软限位。
- 文字变成空心：路径方式选择了轮廓；改为“仅填充”或“轮廓＋填充”。
- 中文缺字或变成方框：换用包含该中文字形的已安装字体，并先在右侧源图预览确认。
