# 个人笔迹离线学习与扩字

本篇说明原来的几何笔形与部件迁移方式。当前新增OLHWG真实轨迹模型作为独立选择，操作和新试样请看[个人笔迹OLHWG离线轨迹扩字使用说明](个人笔迹OLHWG离线轨迹扩字使用说明.md)；下面的模型和试样继续保留供比较。

本次只改个人字库扩展入口。自然书写、内置楷体/黑体/明体、图片、排版、串口和任务发送沿用原实现。原始录字与本机配置不自动改动，生成结果另存新字库。

## 先理解这次做了什么

“个人笔迹学习：真实笔形与部件（离线）”直接读取录字画板的XY点和分笔记录。软件先学习可匹配笔画的形状、端点、弯曲与折钩，再建立真实部件库。新字有已录过的部件时优先使用真实轨迹；其余笔画根据学习到的笔形推算。

例如你已经录了木、日、月、女、子、目、心，因此：

- 林：使用两个你写的木，按左右结构放置。
- 明：使用你写的日、月。
- 好：使用你写的女、子；这份样本中的子是两笔合笔，新字好也保留该习惯，为五笔。
- 想：使用你写的木、目、心。
- 休：复用你写的木，其余两笔由笔形模型推算。

结构字库告诉软件一个字的部件、位置和基本组成；个人轨迹提供实际写法。这种方式是有结构条件的笔迹学习与合成，采用核回归和真实部件复用，不是继续给整字只做缩放/倾斜，也不是宣称已经训练成功了SDT大模型。

## 第一次按这个顺序测试

1. 关闭旧上位机，重新运行“启动上位机.bat”。
2. 打开“文字生成”→“自定义字库 / 100格采样”。
3. 可以直接“导入JSON”，选择exports/个人笔迹_离线学习扩展试样.json。该试样包含原32字和20个重新学习生成的字，共52字；不会覆盖旧字库。
4. 先查看林、明、好、想，点击“回放笔顺”。好应为五笔，体现原来子字的两笔写法。
5. 返回文字生成，选择新库，关闭基础楷体补缺和自然书写，以免混淆字形来自哪里。输入“林明好休想”，先看预览，再沿用已验证设备参数写一行小样。
6. 对比自己录的木、日、月、女、子与新字对应部分。是否像本人仍需个人判断，不将软件测试通过等同为风格验收通过。

## 自己输入内容离线扩展

1. 在字库管理选择最初真实录制的“我的手写体（32字）”。不要将生成字再当成自己的原始录字。
2. 进入“AI扩展（实验）”，点击“用当前录字生成参考样本并打开AI扩展”。
3. 扩字方式选择“个人笔迹学习：真实笔形与部件（离线）”。旧偏好可能仍记着清晰分笔，需要手动选择一次，之后会记忆。
4. 参考目录会自动填好，需包含recorded-font.json。无需模型权重或CUDA；运行Python有NumPy即可，本机环境已具备。
5. 点击“检查录字与目标笔形”。它会真实学习并检查目标字，不只是检查文件存在。日志列出学习笔数、部件数量，以及每个字的来源。
6. 新字库名称改成自己能区分的名称，输入本次文字，每字版本数先选1。
7. 点击“学习并扩展个人字库”。成功后点“导入本次试样到录字画板核对”。结果不会自动连接或发送给写字机。
8. 原始参考目录里的真实录字保留；本次请求中的扩展字会重新生成，因此可以重做旧扩展结果。当前库里其他未请求字保留，旧字库文件本身不修改。

每次最多200种字符。已有真实字不需要重复生成；少量样本和所需结构必须能可靠匹配，否则会说明原因。结构资源覆盖9574字，不等于用32个样本就能把9574字都生成得像本人。

## 参考不足提示是什么意思

本次32字中实际匹配到125笔，建立43种个人部件。对所测20个新字，线、展、需有相似参考不足的笔形，软件会明确列出。这个指标是笔形覆盖提示，不是经过标定的“像本人概率”。即使没有提示，也须核对字形。

这些候选仍可查看，但不能当成已经学好。可在原始字库补录对应的偏旁、折钩或少量代表字，再从真实录字入口重新学习。软件会更新模型；已有导出JSON保持原样，必须重新生成目标字才能看到变化。不能保证补录一个字便能解决全部类似字。

当前没有实现任意少量样本都能准确推断整套个人行书，也不能保证推断出从未提供过的特殊合笔和部件写法。留出字测试中有些字更接近录字，有些未改善；所以本版提供真实学习、来源追踪和参考不足提示，个人相似度仍需小样验收。

同字多版本优先使用真实录字版本或部件候选；没有足够真实变化时，多版可能相同，不编造新的书写习惯。原有自然书写开关仍可单独用于新字库，本次未调整其算法。

## 文件与模型

- 最初真实录字：config/stroke_fonts/中的原库，或自己导出的JSON。
- 参考目录：exports/AI参考样本/<字库标识>/，包含原始recorded-font.json和参考PNG。
- 每次学习任务：.runtime/sdt/jobs/<任务标识>/。
- personal-model.json：本次学习到的笔形回归参数与真实部件轨迹，包含个人数据，只保存在本机。
- font.json：可导入的完整笔画字库。
- summary.json：新增/重做/保留字符、每个字复用的部件、推算笔数与参考不足提示。

学习和扩字完全离线，未上传笔迹，不使用在线API或API Key；导入后的字库写字也不需要联网。新方式不依赖SDT权重，原清晰分笔和SDT实验入口继续保留供比较。

验证见.runtime/personal-learning/smoke/report.json和同目录截图；tests/personal_learning_smoke.py使用真实录字复验离线生成、旧扩展字重做、原字保留、导入回放、G代码和模拟任务。当前未连接真实串口，机械效果需由用户试写验收。
