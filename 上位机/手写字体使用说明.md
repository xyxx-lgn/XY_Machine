打开“文字生成”，选择“笔画 / 单线”模式，在“中文/个人字库”下拉框选择新字体。旁边的“字形对照”可以一次比较16套字体的实际单线字形。每套字体的来源、可绘制字数和简体覆盖情况会在界面显示。鼠标停在选项上也能查看说明。点击排版预览、生成轨迹、导出或载入任务，操作方式与原来一致。

日常简体正文建议先选书卷、轻松、随性、马克笔、圆润或清秀：这6套均支持全部6763个GB2312汉字。其他10套也可直接使用，但部分字体偏繁体；请先预览实际正文，按缺字提示换用覆盖更全的字体。这里的“完整覆盖”仅针对GB2312，不表示包含所有Unicode汉字。

“GB2312汉字覆盖”用6763个汉字核对字库，其中包括不少次常用和生僻字。它与字库总字数不同，总字数还包括繁体、扩展A汉字及符号。部分字体主要面向繁体，简体覆盖较少。请按界面显示的实际覆盖选择；缺字会列出字符并停止生成，不会悄悄换成楷体，也不会漏字发送。

建议先用“你好世界，永田中文。Hello 123”比较不同字形，再生成一小段自己的文字。首次实机验证使用已验证的字号、XY速度、抬笔高度和Z速度；字体本身不会更改这些参数。自然书写可以开关，字形、字距和行内起伏参数继续生效。英文与数字仍由原来的英文样式选择控制。

字体选择和生成参数会保存，下次打开继续使用。所有新字体的轨迹都已预先制作，运行时不联网、不调用AI，也不需要安装原始TTF文件。

16套新资源合计约260MiB。复制或备份程序时请一并保留assets/strokes/centerline及其许可文件；正常生成按需读取单字，不会一次展开全部字库。原有三套中文内置库保留，新增后共19套。

开发者如需重建字库，在上位机目录运行以下命令。准备过程需要联网，正常用户无需执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r tools/requirements-font-build.txt
.\.venv\Scripts\python.exe tools/build_handwriting_fonts.py --download
.\.venv\Scripts\python.exe tools/build_handwriting_fonts.py --jobs 6
```

下载的原始字体放在.runtime/font-sources/handwriting，正式离线资源放在assets/strokes/centerline。字库构建工具与日常文字生成相互独立。
